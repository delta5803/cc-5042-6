# 测试说明

运行：`npm test`（Node 内置 test runner，零第三方依赖）。

## 测试文件

### `test/geometry-projection.test.js`
- 矩形相交/包含、点在多边形内（射线法）；
- 最大内切点位于多边形内部、退化多边形回退质心；
- 世界↔屏幕变换在含旋转情况下互逆；缩放线性关系。

### `test/measure-candidate.test.js`
- 同字符数的 `iiii`/`WWWW`、CJK/拉丁宽度显著不同，证伪“字符数 × 固定宽度”；
- 长名称宽度可按逐字推进量独立复算；
- `CanvasTextMeasurer` 用模拟 canvas 验证取 `actualBoundingBox*` 的真实边界与缓存；
- 候选顺序为固定常量、矩形尺寸与度量一致、区域居中候选围绕锚点。

### `test/labeler.test.js`（核心）
| 测试 | 验证点 |
| --- | --- |
| 确定性 | 同一输入 5 次布局快照逐字节一致；无随机源；密集场景同时有放置与隐藏 |
| 排序 | 优先级降序 → 点先区域 → id 升序 |
| 屏幕/世界分离 | 密集旋转点群中找出世界距离 > 2 倍标签高但屏幕矩形真实相交的碰撞对；旋转前后拒绝明细不同 |
| 优先级 | 高优先先占位，低优先改走其他候选且候选试探含 `label-collision` |
| 跨画布边缘 | 屏幕外要素全部候选 `off-canvas`；边缘内要素正常放置 |
| 缩放重映射 | 放大放置数 ≤ 缩小放置数，两场景均无碰撞 |
| DPR 不变性 | dpr=1 与 dpr=3 的 CSS 像素矩形完全相同 |
| 区域标签 | 小区域居中候选被拒并继续外移；正常区域居中放置；锚点在环内 |
| 标记障碍 | 紧密点群封死候选时出现真实 `marker-collision`/`label-collision` |
| 稳定性 | 平移 1 世界单位后共同可见标签的候选位置保持率 ≥ 80% |
| 异常 | 缺少度量器等非法输入抛错，由界面层提示 |

每个布局测试都调用独立于引擎实现的 `assertNoOverlappingLabels`（两两 AABB 真值）
与 `assertWithinCanvas`（边缘真值）复核，而非仅信任引擎自身输出。

## CLI 自检

`node src/cli/cli.js selfcheck` 对示例数据跑默认、旋转 45°、放大、缩小、小视口五个场景并
打印实际放置/隐藏统计；`report --json` 输出机器可读结果供外部核对。
